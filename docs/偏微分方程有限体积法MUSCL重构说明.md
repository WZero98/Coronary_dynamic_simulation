# MUSCL重构示例

下面用一个**一维Burgers方程**的非线性激波问题，完整展示**从有限体积法离散**到**MUSCL重构**、**minmod限制器**应用、再到**数值通量计算**的全过程，并给出具体数值。

---

## 1. 控制方程与问题设置

Burgers方程（无粘、非线性）：

\[
\frac{\partial u}{\partial t} + \frac{\partial}{\partial x}\left(\frac{u^2}{2}\right) = 0
\]

初值（含间断与光滑区）：

\[
u(x,0) =
\begin{cases}
2.0, & x \le 0.5 \\
1.0, & x > 0.5
\end{cases}
\]

计算域 \(x \in [0,1]\)，网格：\(N=10\) 个均匀单元，单元宽度 \(\Delta x = 0.1\)。

只演示**一个典型单元** \(i=5\)（中心 \(x_5=0.45\)，区间 \([0.4,0.5]\)）上的**重构**过程，初值在该单元附近如下：

| 单元 \(i\) | \(x_i\)（中心） | 单元平均值 \(\bar{u}_i\) |
|-----------|----------------|--------------------------|
| 4 | 0.35 | 2.0 |
| 5 | 0.45 | 2.0 |
| 6 | 0.55 | 1.0 |
| 7 | 0.65 | 1.0 |

单元 5 位于间断左侧（光滑区），但接近间断。

---

## 2. 有限体积法基础（半离散形式）

对于单元 \(i\)：

\[
\frac{d\bar{u}_i}{dt} + \frac{1}{\Delta x}\left( f_{i+1/2} - f_{i-1/2} \right) = 0
\]

其中 \(f = u^2/2\)，\(f_{i+1/2}\) 是界面上的数值通量。

**一阶Godunov** 直接用 \(\bar{u}_i\)、\(\bar{u}_{i+1}\) 重构常数，再求通量。

**MUSCL** 的目标：用单元平均值**重构出界面左右状态** \(u_{i+1/2}^L\) 和 \(u_{i+1/2}^R\)，再通过Riemann求解器得到 \(f_{i+1/2}\)。

---

## 3. MUSCL 线性重构（未经限制）

对于单元 \(i\)，假设单元内 \(u(x)\) 线性变化：

\[
u(x) = \bar{u}_i + \sigma_i \frac{x - x_i}{\Delta x}
\]

斜率 \(\sigma_i\) 用中心差分近似（**无限制**）：

\[
\sigma_i = {\bar{u}_{i+1} - \bar{u}_{i-1}}
\]

对单元 5（\(i=5\)）：
\[
\sigma_5 = {\bar{u}_6 - \bar{u}_4} = {1.0 - 2.0} = -1
\]

界面 \(i+1/2\)（即单元 5 与单元 6 之间，位于 \(x=0.5\)）：

- **左状态**（来自单元 5）：  
  \(u_{5+1/2}^L = \bar{u}_5 + \sigma_5 \cdot (\frac{0.5-0.45}{0.1}) = 2.0 + (-0.5) = 1.5\)

- **右状态**（来自单元 6）：  
  需要先算 \(\sigma_6 = {\bar{u}_7 - \bar{u}_5} = {1.0 - 2.0} = -1\)  
  \(u_{5+1/2}^R = \bar{u}_6 + \sigma_6 \cdot (\frac{0.5-0.55}{0.1}) = 1.0 + 0.5 = 1.5\)

如果直接这样用，界面上左右状态都是 1.5，通量没问题。  
但再看**界面 \(i-1/2\)**（单元 4 与 5 之间，\(x=0.4\)）：

- 左状态来自单元 4：  
  \(\sigma_4 = {2.0 - 2.0} = 0\)，  
  \(u_{4+1/2}^L = 2.0 + 0 = 2.0\)

- 右状态来自单元 5：  
  按无限制斜率 \(\sigma_5 = -1\)，  
  \(u_{4+1/2}^R = 2.0 + (-1)(\frac{0.4-0.45}{0.1}) = 2.5\)

这里**出现严重问题**：  
单元 5 右界面值 2.5 **超出了相邻单元平均值 2.0 和 1.0 的范围**。  
若直接计算通量，会产生**虚假振荡**，甚至负能量或发散。这正是需要限制器的原因。

---

## 4. 加入 minmod 限制器

minmod 函数定义：

\[
\text{minmod}(a,b) =
\begin{cases}
a & \text{if } |a| < |b| \text{ 且 } ab > 0 \\
b & \text{if } |b| < |a| \text{ 且 } ab > 0 \\
0 & \text{if } ab \le 0
\end{cases}
\]

简化为：符号一致则取绝对值更小的；否则取 0。

### 计算单元 5 的**限制后斜率**

斜率候选：
- 左差：\(\Delta_- = \bar{u}_5 - \bar{u}_4 = 2.0 - 2.0 = 0\)
- 右差：\(\Delta_+ = \bar{u}_6 - \bar{u}_5 = 1.0 - 2.0 = -1.0\)

minmod 取法（van Leer型常用）：
\[
\sigma_i^{\text{lim}} = \text{minmod}(\Delta_-, \Delta_+)
\]
\[
\text{minmod}(0, -1.0) = 0 \quad (\text{因为乘积 }0\times(-1.0)=0 \le 0)
\]

所以 **\(\sigma_5 = 0\)**。

原来无限制斜率为 -0.5 → 现在为 **0**。

### 重新计算界面 \(i-1/2=4.5\)（单元 5 左侧）

\[
u_{4+1/2}^R = \bar{u}_5 - \sigma_5 = 2.0 - 0 = 2.0
\]

不再出现 2.5 这个危险值。

### 界面 \(i+1/2=5.5\)（单元 5 右侧）

\[
u_{5+1/2}^L = \bar{u}_5 + \sigma_5 = 2.0 + 0 = 2.0
\]

即使单元 6 的右状态仍可能保持 \(u_{5+1/2}^R\) 来自其自身限制：

对单元 6：  
\(\Delta_- = 1.0 - 2.0 = -1.0\)，\(\Delta_+ = 1.0 - 1.0 = 0\)  
\(\text{minmod}(-1.0, 0) = 0 \quad \Rightarrow \sigma_6=0\)  
\(u_{5+1/2}^R = \bar{u}_6 - \sigma_6 = 1.0\)

**界面上的左右状态**：  
左 \(=2.0\)，右 \(=1.0\)（间断被清晰保持）。

---

## 5. Riemann 求解器求通量

使用**精确或近似 Riemann 解**（这里用Roe通量）：  
Burgers 方程激波速度 \(S = (u_L+u_R)/2 = (2.0+1.0)/2 = 1.5\)。

激波向右传播，通量取左状态对应的通量：

\[
f_{i+1/2} = \frac{u_L^2}{2} = \frac{2.0^2}{2} = 2.0
\]

对比一阶格式：若直接用 \(\bar{u}_5=2.0\) 和 \(\bar{u}_6=1.0\)，通量也是 2.0，但 MUSCL 的优势在于**右侧单元若线性区域则精度提高**。

---

## 6. 整体效果对比

| 单元 5 附近 | 一阶 Godunov | 无限制 MUSCL | minmod-MUSCL |
|-------------|--------------|--------------|----------------|
| 界面左状态 | 2.0 | 2.5（危险） | 2.0 |
| 间断分辨率 | 模糊 | 振荡 | **清晰无振荡** |
| 光滑区精度 | 一阶 | 二阶（但会振荡） | 二阶（恢复） |

在有激波时 minmod 让该单元退回一阶；若在光滑区（如单元 3 左右邻居变化平缓），minmod 会保留较大斜率，实现二阶精度。

---

## 7. 总结

通过这个 **Burgers 方程 + minmod** 的例子，可以清楚看到 MUSCL 的完整逻辑：

1. **有限体积框架**：每个单元存储平均值。
2. **线性重构**：用斜率表示单元内变化。
3. **minmod 限制器**：
   - 比较左右差分的符号与大小。
   - 符号异或有一个为零 → 斜率强制为零（保单调）。
4. 用限制后斜率重构界面左右状态。
5. Riemann 求解器得到通量。

于是，MUSCL 在光滑区实现**二阶精度**，在激波处自动回归**一阶单调性**，既不振荡，又整体提高分辨率——这正是它成为 CFD 经典方法的原因。

在MUSCL（Monotone Upstream-centered Schemes for Conservation Laws）框架中，从单元平均值 \(\bar{u}_i\) 计算重构斜率 \(\sigma_i\) 的方法有多种，核心差异在于**精度**、**对网格的适应性**以及**引入限制器的便利性**。


# MUSCL斜率算法
这里按**基础差分公式**和**考虑限制器的变体**两大类，列出最常见的斜率算法。

---

## 一、 基础差分公式（无限制）

这些公式计算出的斜率 **尚未经过限制器处理**，是 MUSCL 重构的起点。

### 1. 中心差分 (Central Difference) —— **最经典、二阶精度**
- **公式**：
  \[
  \sigma_i = \frac{\bar{u}_{i+1} - \bar{u}_{i-1}}{2}
  \]
- **精度**：二阶
- **特点**：
  - 在光滑区域能给出最高精度的斜率。
  - 在间断附近会产生振荡，**必须配合限制器使用**。
  - 上一轮对话中的例子采用的就是此方法，然后被 minmod 限制。

### 2. 迎风/单侧差分 (Upwind / One-sided)
- **迎风公式（根据特征方向选取）**：
  \[
  \sigma_i = \bar{u}_i - \bar{u}_{i-1} \quad \text{或} \quad \sigma_i = \bar{u}_{i+1} - \bar{u}_i
  \]
- **精度**：一阶
- **特点**：
  - 非常稳定，本身就是单调的，**无需限制器**。
  - 严重耗散，无法提升格式精度，很少单独使用，但在某些 TVD 格式中作为下限基准。

### 3. 最小二乘梯度 (Least-Squares Gradient) —— **用于非结构网格**
- **公式**：求解超定系统
  \[
  \min_{\sigma_i} \sum_{j \in N(i)} \left[ (\bar{u}_j - \bar{u}_i) - \sigma_i \cdot (x_j - x_i) \right]^2
  \]
  其中 \(N(i)\) 是单元 \(i\) 的邻接单元集合。
- **精度**：二阶（依赖于网格质量）
- **特点**：
  - **非结构网格的标配**，无需网格拓扑规则。
  - 计算量较大，需要求解局部最小二乘问题。
  - 同样需要限制器来保证单调性。

---

## 二、 含限制器的斜率计算（直接求限制后斜率）

这些方法将**差分与限制过程合二为一**，直接给出最终用于重构的斜率 \(\sigma_i^{\text{lim}}\)。它们通常利用**斜率比 \(r\)** 的概念。

### 4. Van Leer 型限制 (使用 minmod 或 Van Leer 函数)
- **公式（以 minmod 为例）**：
  \[
  \sigma_i^{\text{lim}} = \text{minmod}(\bar{u}_i - \bar{u}_{i-1},\ \bar{u}_{i+1} - \bar{u}_i)
  \]
- **本质**：取左差与右差中**绝对值较小且符号相同**的那个，否则取 0。
- **特点**：
  - 这是**最经典、最稳健**的斜率限制算法。
  - 相当于先计算中心差分斜率，然后施加最保守的限制。
  - 上一轮例子中我们实际使用的就是这个：\(\sigma_5 = \text{minmod}(0.0, -1.0) = 0.0\)。

### 5. 通量限制器形式 (将限制器应用于斜率比)
许多文献将斜率表示为 **\(\sigma_i = \phi(r_i) \cdot (\bar{u}_{i+1} - \bar{u}_i)\)**，其中斜率比：
\[
r_i = \frac{\bar{u}_i - \bar{u}_{i-1}}{\bar{u}_{i+1} - \bar{u}_i}
\]
常用限制器函数 \(\phi(r)\)：

| 限制器 | \(\phi(r)\) 公式 | 特点 |
| :--- | :--- | :--- |
| **minmod** | \(\max(0,\ \min(1,\ r))\) | 最保守，耗散大 |
| **van Leer** | \(\frac{r + |r|}{1 + |r|}\) | 平滑过渡，综合性能好 |
| **Superbee** | \(\max(0,\ \min(1,\ 2r),\ \min(2,\ r))\) | 最激进，锐利但可能阶梯 |
| **van Albada** | \(\frac{r^2 + r}{r^2 + 1}\) | 光滑可微，收敛性好 |

- **精度**：在光滑区 \((r\approx1)\) 恢复二阶精度 \((\phi=1)\)；在间断处 \((r<0)\) 退化为零。
- **特点**：便于理论分析 TVD 性质，也是主流实现方式。

### 6. 常数 / 零斜率 —— **退化为 Godunov 格式**
- **公式**：
  \[
  \sigma_i^{\text{lim}} = 0
  \]
- **精度**：一阶
- **特点**：这不是“算法”，而是限制器在间断处作用的**极限结果**（如 minmod 在两个差反号时）。在光滑区若使用此值，则无法获得二阶精度。

---

## 三、 总结对比表

| 算法 | 精度潜力 | 是否需单独限制器 | 适用网格 | 常用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **中心差分** | 二阶 | ✅ 必须 | 结构网格 | 作为计算**候选斜率**的中间步骤 |
| **单侧差分** | 一阶 | ❌ 不需 | 任意 | 极限耗散基准，很少单独用 |
| **最小二乘梯度** | 二阶 | ✅ 必须 | **非结构网格** | 复杂几何的核心方法 |
| **minmod 直接限制** | 二阶（光滑区）| ❌ 已集成 | 结构网格 | 教学、最稳健实现 |
| **通量限制器形式** | 二阶（光滑区）| ❌ 已集成 | 结构网格 | 工业 CFD 主流（如 van Leer） |
| **零斜率** | 一阶 | ❌ 不适用 | 任意 | 间断处的自动结果，非主动选择 |

---

## 回到上轮 Burger 方程的例子

当时我们实际执行的是 **minmod 直接限制算法**：
1. **计算左右差**：\(\Delta_- = \bar{u}_5 - \bar{u}_4 = 0\)，\(\Delta_+ = \bar{u}_6 - \bar{u}_5 = -1.0\)
2. **应用 minmod**：\(\sigma_5^{\text{lim}} = \text{minmod}(0.0, -1.0) = 0.0\)

如果改用 **中心差分 + 后置 minmod 限制**：
1. 先算候选斜率：\(\sigma_5^{\text{cand}} = (\bar{u}_6 - \bar{u}_4)/2 = (1.0-2.0)/2 = -0.5\)
2. 再与两侧差比较限制：\(\sigma_5^{\text{lim}} = \text{minmod}(-0.5,\ 2(\bar{u}_5-\bar{u}_4),\ 2(\bar{u}_6-\bar{u}_5))\) 等变体，最终也是 0.0。

**关键结论**：对于间断附近的单元，无论哪种含限制器的算法，最终都会将斜率限制为 0；而在光滑区，**中心差分 + van Leer 限制器**是工业界最主流的组合，因为它提供了“在安全边际内尽量保持二阶精度”的最佳平衡。


# 线性重构斜率推导

---

这个公式

\[
u(x) = \bar{u}_i + \sigma_i \frac{x - x_i}{\Delta x / 2}
\]

中的分母 \(\Delta x / 2\) 不是随意写的，它本质上是为了**数学上的简洁和几何上的对称**。

简单直接的回答是：**这样做是为了让斜率 \(\sigma_i\) 直接等于从单元中心到界面处的差值。**

让我们详细拆解一下。

## 1. 核心原因：变量定义域的归一化

在MUSCL格式中，我们通常将每个单元 \(i\) 映射到一个**标准化的局部坐标系**中。令局部坐标 \(\xi \in [-1, 1]\)，其中：

-   \(\xi = -1\) 代表单元左界面 \(x_{i-1/2}\)
-   \(\xi = 0\) 代表单元中心 \(x_i\)
-   \(\xi = +1\) 代表单元右界面 \(x_{i+1/2}\)

这个映射关系是：
\[
x = x_i + \frac{\Delta x}{2} \xi \quad \Leftrightarrow \quad \xi = \frac{x - x_i}{\Delta x / 2}
\]

现在，单元内的线性重构可以非常自然地写成关于 \(\xi\) 的函数：
\[
u(\xi) = \bar{u}_i + \sigma_i \cdot \xi
\]

这正是你提供的公式的由来。当你把 \(\xi\) 的定义代入，就得到了原公式：
\[
u(x) = \bar{u}_i + \sigma_i \cdot \frac{x - x_i}{\Delta x / 2}
\]

## 2. 这种定义的两个好处

**好处一：界面值表达最简**
在这种定义下，斜率 \(\sigma_i\) 有了非常明确的几何意义：

-   在右界面 \((\xi=1)\)： \(u_{i+1/2}^L = \bar{u}_i + \sigma_i\)
-   在左界面 \((\xi=-1)\)： \(u_{i-1/2}^R = \bar{u}_i - \sigma_i\)

**可以看到，\(\sigma_i\) 就是中心平均值 \(\bar{u}_i\) 到界面重构值的增量**。这个简洁的表达是大多数后续推导的基础。

**好处二：避免分数出现**
如果不做这种缩放，直接写成 \(u(x) = \bar{u}_i + \sigma_i (x - x_i)\) 的形式，那么在计算界面值时：
\[
u_{i+1/2}^L = \bar{u}_i + \sigma_i \cdot \frac{\Delta x}{2}
\]
这会多出一个麻烦的 \(\Delta x/2\) 因子。后续在计算通量或进行限制器操作时，这个因子会一直出现，增加代数运算的繁琐程度和出错概率。

## 3. 与你记忆中“除以 \(\Delta x\)”的关系

你可能习惯的是另一种定义：
\[
u(x) = \bar{u}_i + \sigma_i' \frac{x - x_i}{\Delta x}
\]
这种情况下 \(\sigma_i'\) 表示的是**整个单元宽度上的总变化量**。

-   用 \(\sigma_i\)（我们的定义）： 界面增量 = \(\sigma_i\)。
-   用 \(\sigma_i'\)（你的记忆）： 界面增量 = \(\sigma_i' \cdot \frac{1}{2}\)。

这两个定义是等价的，只是差了一个因子2：\(\sigma_i = \frac{\sigma_i'}{2}\)。

## 总结

公式中采用 \(\Delta x / 2\) 的原因可以归纳为：

-   **数学映射**：它本质上是将物理单元映射到标准化的局部坐标系 \([-1, 1]\)。
-   **核心优势**：使**斜率 \(\sigma_i\) 直接成为单元平均值到界面值的增量**，从而简化了公式推导和代码实现。
-   **不是错误**：这是MUSCL类格式中非常主流且标准的写法。如果你在其他地方看到“除以 \(\Delta x\)”的版本，它们本质上是等价的，只是对斜率因子的定义不同。

希望这个解释能帮助你理解这个“1/2”的来由。


# Riemann 求解器的目的

**Riemann 求解器的目的是算出：**

> **网格界面上，单位时间、单位面积通过的物理量（即数值通量）。**

有了这个数值通量之后，再代入有限体积法的公式：

\[
\bar{u}_i^{n+1} = \bar{u}_i^{n} - \frac{\Delta t}{\Delta x} \left( F_{i+1/2} - F_{i-1/2} \right)
\]

才能把**下一时刻的单元平均值** \(\bar{u}_i^{n+1}\) 算出来。

---

## 1. 一个更清晰的链条

整个逻辑链是：

1. 已知：当前时刻每个单元的 **平均值** \(\bar{u}_i^n\)。
2. 通过 MUSCL 重构 → 得到界面左右状态 \(u_L, u_R\)。
3. **Riemann 求解器**：输入 \(u_L, u_R\) → 输出界面通量 \(F_{i+1/2}\)。
4. 用通量更新平均值 → 得到 \(\bar{u}_i^{n+1}\)。

所以 Riemann 求解器处于 **“从状态到通量”** 这个关键位置。

---

## 2. 为什么不能直接把平均值代入通量函数？

你可能会想：

> 既然 \(f(u)\) 是已知函数，为什么不能直接算 \(f(\bar{u}_i)\)？

因为：

- 在界面处，左右状态 \(u_L \neq u_R\)（不连续）
- 通量函数 \(f\) 是**非线性**的
- 直接取 \(f\left(\frac{u_L+u_R}{2}\right)\) 会**丢失激波/稀疏波的传播信息**

> Riemann 求解器的本质：  
> 在已知 \(u_L, u_R\) 的情况下，**正确估计界面上的通量**，使数值解满足守恒律、熵条件和波传播方向。

---

## 3. 用一句话总结你的说法

> “Riemann 求解器把离散后的微分方程的值给计算出来” ——  
> ✅ 如果这里的“值”指的是 **界面通量**，那就完全正确。  
> ❌ 如果指的是单元平均值，那就是把角色搞混了（那是更新公式做的事）。

| 组件 | 输入 | 输出 |
|------|------|------|
| MUSCL | 平均值 \(\bar{u}_{i-1},\bar{u}_i,\bar{u}_{i+1}\) | 界面左右状态 \(u_L, u_R\) |
| **Riemann 求解器** | 界面左右状态 \(u_L, u_R\) | **界面通量** \(F_{i+1/2}\) |
| 有限体积更新 | 界面通量 \(F_{i\pm1/2}\) | 下一时刻平均值 \(\bar{u}_i^{n+1}\) |


## 5. 实例

下面用一个**Burgers方程 + HLL Riemann求解器**的完整数值例子，从MUSCL重构 → Riemann求解器 → 通量 → 更新平均值，**全部手算一遍**。

---

### 1. 问题设置

**方程**：
\[
\frac{\partial u}{\partial t} + \frac{\partial}{\partial x}\left(\frac{u^2}{2}\right) = 0
\]

**网格**：均匀网格，\(\Delta x = 0.1\)，只关注**一个界面** \(i+1/2 = 5.5\)（位于 \(x=0.5\)）

**已知当前时刻的平均值**（已通过MUSCL+minmod得到）：
- \(\bar{u}_5 = 2.0\)
- \(\bar{u}_6 = 1.0\)

**MUSCL 重构结果**（限制后）：
- 单元5斜率 \(\sigma_5 = 0\) → \(u_{5+1/2}^L = 2.0\)
- 单元6斜率 \(\sigma_6 = 0\) → \(u_{5+1/2}^R = 1.0\)

**界面左右状态**：
\[
u_L = 2.0, \quad u_R = 1.0
\]

目标：用 **HLL Riemann求解器** 计算数值通量 \(F_{5+1/2}\)。

---

### 2. HLL Riemann 求解器算法（Burgers版）

**步骤1：估计波速**  
对于Burgers方程，特征速度 \(f'(u) = u\)。HLL 波速取：
\[
S_L = \min(u_L, u_R, 0)
\]
\[
S_R = \max(u_L, u_R, 0)
\]
包含0是为了处理稀疏波跨越界面的情况。

计算：
\[
S_L = \min(2.0,\ 1.0,\ 0) = 0
\]
\[
S_R = \max(2.0,\ 1.0,\ 0) = 2.0
\]

**步骤2：判断界面 \(x=0\) 落在哪个区域**

- 若 \(S_L \ge 0\)：通量取 \(f(u_L)\)
- 若 \(S_R \le 0\)：通量取 \(f(u_R)\)
- 若 \(S_L < 0 < S_R\)：通量取 \(f(u_{HLL})\)

这里 \(S_L = 0\)，\(S_R = 2.0\)。\(S_L \ge 0\) 条件成立吗？  
严格来说 \(S_L = 0\) 属于边界情况。对于Burgers方程，当 \(S_L = 0\) 时，界面恰好位于左波上，此时取 \(f(u_L)\) 和 \(f(u_{HLL})\) 是等价的。为了确定，我们直接用**HLL公式的分支**：

通常取：
\[
F_{HLL} = 
\begin{cases}
f(u_L), & 0 \le S_L \\
\frac{S_R f(u_L) - S_L f(u_R) + S_L S_R (u_R - u_L)}{S_R - S_L}, & S_L < 0 < S_R \\
f(u_R), & S_R \le 0
\end{cases}
\]

这里 \(S_L = 0\)，属于第一分支：\(F = f(u_L)\)。

**步骤3：计算通量**
\[
f(u_L) = \frac{u_L^2}{2} = \frac{2.0^2}{2} = 2.0
\]

因此：
\[
F_{5+1/2} = 2.0
\]

---

### 3. 用有限体积法更新平均值（验证）

假设左侧界面通量 \(F_{4+1/2} = 2.0\)（左侧均匀），时间步长 \(\Delta t = 0.01\)。

单元5更新：
\[
\bar{u}_5^{n+1} = \bar{u}_5^{n} - \frac{\Delta t}{\Delta x} \left( F_{5+1/2} - F_{4+1/2} \right)
= 2.0 - \frac{0.01}{0.1} (2.0 - 2.0) = 2.0
\]

单元6更新：
\[
\bar{u}_6^{n+1} = \bar{u}_6^{n} - \frac{\Delta t}{\Delta x} \left( F_{6+1/2} - F_{5+1/2} \right)
\]
假设 \(F_{6+1/2} = 0.5\)（右侧均匀区通量），则：
\[
\bar{u}_6^{n+1} = 1.0 - \frac{0.01}{0.1} (0.5 - 2.0) = 1.0 - 0.1 \times (-1.5) = 1.0 + 0.15 = 1.15
\]

单元6的值增加，因为激波向右传播，把左侧的高值带入。

---

### 4. 对比：如果直接用算术平均（错误做法）

如果错误地取 \(u_{avg} = (u_L+u_R)/2 = 1.5\)，则：
\[
F_{wrong} = f(1.5) = 1.125
\]

与正确通量 \(2.0\) 相比，误差高达 **44%**！而且这个错误通量会导致：
- 激波传播速度被低估
- 数值解过度耗散，激波变模糊

这就是为什么 **必须使用Riemann求解器**，而不能简单取平均。

---

### 5. 完整流程总结表

| 步骤 | 操作 | 输入 | 输出 | 本例结果 |
|------|------|------|------|----------|
| 1 | MUSCL重构 | \(\bar{u}_{i-1},\bar{u}_i,\bar{u}_{i+1}\) | \(u_L, u_R\) | \(u_L=2.0, u_R=1.0\) |
| 2 | 估计波速 | \(u_L, u_R\) | \(S_L, S_R\) | \(S_L=0, S_R=2.0\) |
| 3 | 判断区域 | \(S_L, S_R\) | 分支选择 | \(S_L \ge 0\) → 第一分支 |
| 4 | 计算通量 | \(u_L\)（或 \(u_{HLL}\)） | \(F_{i+1/2}\) | \(F=2.0\) |
| 5 | 更新平均值 | \(F_{i\pm1/2}\) | \(\bar{u}_i^{n+1}\) | \(\bar{u}_5=2.0, \bar{u}_6=1.15\) |

---

### 6. 关键结论

> **Riemann求解器把“界面左右状态” → “数值通量”**，这一步无法用简单平均替代，尤其在有激波时。

本例中：
- 正确通量 = 2.0
- 算术平均通量 = 1.125（错误）
- 相对误差 = 44%

这个数值例子完整展示了：**从已知平均值 → MUSCL重构 → HLL Riemann求解器 → 通量 → 更新平均值** 的全过程，并且量化了不使用Riemann求解器会造成的巨大误差。
